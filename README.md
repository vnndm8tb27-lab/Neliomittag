# Neliomittag

Eine kleine responsive Web-App/PWA für die gemeinsame Mittagessen-Planung.

## Online stellen
Das Projekt ist für einen **Render Web Service** vorbereitet. Render kann das GitHub-Repository direkt als Node/Express-App deployen. Die Datei `render.yaml` enthält die Grundeinstellungen.

Repo: https://github.com/vnndm8tb27-lab/Neliomittag

## Lokal starten
Node.js 18+: `npm install` und danach `npm start`.

## Handy-App
Nach dem Online-Deployment kann die Seite auf iPhone/Android als App zum Home-Bildschirm hinzugefügt werden.

## Wichtig zur Speicherung
Die aktuelle Version speichert Einträge in `data.json`. Auf einem normalen Cloud-Deployment ist der lokale Dateispeicher nicht dauerhaft garantiert. Für einen echten Dauerbetrieb sollte später eine persistente Datenbank (z. B. PostgreSQL) angeschlossen werden.
